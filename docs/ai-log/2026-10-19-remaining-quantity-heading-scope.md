# 남은 수량 조회 소제목을 추가하는 정리는 미룬다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | OPEN 초기화 절의 remainingQuantity 조회 계약을 별도 소제목으로 분리한다 |
| 왜 틀렸나 | 과잉. 조회 계약의 내용과 API 응답은 이미 일치한다. 이번 마지막 수정은 보상 Lua의 키 유실 오류를 막는 범위이며 추가 목차 편집은 넓히지 않는다 |
| 어떻게 알았나 | 문서 대조. 02와 OpenAPI가 단건 GET, 목록 MGET, 키 없음과 Redis 실패의 null 응답을 같은 조건으로 정한다 |
| 대신 한 것 | 조회 문단의 위치는 유지하고 필수 키 유실 가드와 복구 계약을 보강했다. PR #120 |
