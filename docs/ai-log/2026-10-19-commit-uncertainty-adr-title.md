# 커밋 불확실 ADR의 제목을 유지한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | ADR 0021의 제목과 파일명을 보상 금지가 드러나는 문장으로 바꾸고 계획 목록도 맞춘다. |
| 왜 틀렸나 | 과잉. 제목의 명확화는 가능하지만 본문은 커밋 불확실 직후의 자동 보상 금지와 주문 인스턴스를 중지한 뒤의 수동 복원을 구별한다. 호출 시점의 재고 유지 결정과 운영 복원 절차가 충돌하지 않아 제목과 파일명을 추가 변경하지 않았다. |
| 어떻게 알았나 | 설계 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/135#issuecomment-6260873911)을 ADR 0021의 결정 및 수동 복원 항목과 02 문서 2절의 복구 절차에 대조했다. 둘 다 커밋 불확실 직후의 자동 보상을 금지하고 모든 주문 인스턴스와 미처리 쓰기를 중지한 뒤에만 수동 복원을 허용한다. |
| 대신 한 것 | 기존 제목을 유지하고 자동 처리와 수동 복원은 결정 본문을 정본으로 삼는다. PR #135. |
