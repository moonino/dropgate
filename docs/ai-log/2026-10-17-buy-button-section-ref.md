# 구매 버튼 항목을 6절 참조로 줄이지 않는다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-17, Claude Code 자동 리뷰 제안 |
| 제안 요지 | 10 문서 7절의 구매 버튼 항목(121행)이 오류 code별 동작을 6절 표와 겹쳐 적으니, 동작은 6절에만 두고 7절에는 버튼 문구와 모양만 남긴 뒤 6절을 가리킨다. |
| 왜 틀렸나 | 과잉. 겹친다고 본 부분은 같은 규칙을 두 번 적은 것이 아니다. 6절 표의 DROP_NOT_OPEN, SOLD_OUT, ALREADY_PURCHASED, NOT_ADMITTED 행은 "구매 버튼을 해당 상태로 바꾸고 message 표시"까지만 정한다. code를 받았을 때의 버튼 문구("품절", "이미 구매함", "입장 필요")와 서버 message를 버튼 아래에 둔다는 위치는 7절 121행에만 있다. 7절을 6절 참조로 줄이면 중복을 없애는 범위를 넘어 7절만 정하는 정보까지 지운다. |
| 어떻게 알았나 | 설계 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/98#issuecomment-6231090648)의 세 번째 항목을 리뷰 당시 `docs/design/10-웹-프론트.md`의 6절 71행, 7절 121행과 맞대어 보았다. 6절 행에는 버튼 문구도 message 위치도 없었다. 기각 이유는 PR #98 리뷰 반영 커밋 본문의 기각한 제안 항목에 적었다. |
| 대신 한 것 | 7절 구매 버튼 항목과 6절 표를 모두 그대로 둔다. PR #98 |
