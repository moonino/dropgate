# 부분 키 초기화의 두 단언을 유지한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | 기존 stock 수량 보존 테스트에서 meta 생성 단언을 빼거나 별도 테스트로 나눈다. |
| 왜 틀렸나 | 과잉. 기존 stock만 있는 부분 키 상태의 초기화 결과가 한 개념이다. 수량 보존과 meta 생성을 함께 검증해야 stock이 있다는 이유로 초기화를 전부 건너뛰는 회귀도 잡는다. |
| 어떻게 알았나 | 설계 문서 대조와 테스트. 02 문서는 meta가 없으면 meta를 만들고 stock은 SET NX로 보존하도록 정한다. 실제 Redis에서 두 결과를 함께 검증한 테스트와 전체 회귀가 통과했다. [리뷰](https://github.com/moonino/dropgate/pull/127#issuecomment-6260393720). |
| 대신 한 것 | 두 단언을 같은 테스트에 유지했다. PR #127. |
