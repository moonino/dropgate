# 등록 액션의 인증 우선순위를 유지한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | parseDropForm을 runAuthenticatedAction 앞으로 옮겨 입력 오류를 인증 복구보다 먼저 반환한다. |
| 왜 틀렸나 | 과잉. 콜백의 모양을 통일하려는 정리가 쿠키가 없는 요청의 관찰 가능한 결과를 재발급에서 입력 오류로 바꾼다. 이번 작업은 모든 인증 액션이 쿠키 부재를 재발급 결과로 돌려주는 경계를 연결하며 입력 검증과 인증의 우선순위를 변경하는 범위가 아니다. |
| 어떻게 알았나 | 테스트와 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/147#issuecomment-6261418457)과 원본117 실행 보충의 액세스 쿠키가 없는 서버 액션 조건을 비교했다. 빈 입력과 쿠키 부재를 함께 보낸 등록 액션이 refresh-required를 반환하는 테스트를 통과했다. |
| 대신 한 것 | 기존 인증 우선순위를 유지하고 쿠키 부재 테스트의 입력을 빈 폼으로 바꿔 해당 계약을 고정했다. PR #147. |
