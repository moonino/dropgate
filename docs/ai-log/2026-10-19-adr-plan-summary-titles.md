# 계획의 ADR 목록은 결정 요약을 유지한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | plan.md의 ADR 0021과 0022 항목을 ADR 제목과 정확히 같은 문구로 바꾼다. |
| 왜 틀렸나 | 과잉. 기존 목록도 ADR 0002 등을 제목과 다른 결정 요약으로 적는다. 번호가 정본 ADR을 식별하고 현재 요약은 보상 조건만 바뀐 범위와 중간 기본값을 명확히 전달한다. 제목과 같은 문구만 허용하는 규칙은 없다. |
| 어떻게 알았나 | 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/135#issuecomment-6260976896)을 CONTRIBUTING.md 6절과 plan.md의 기존 목록에 대조했다. 0002의 실제 제목은 서비스 셋과 비동기 경계 하나이고 목록은 서비스 셋으로 나눈 이유와 경계다. |
| 대신 한 것 | 번호별 결정 요약을 유지하고 ADR 0021의 0007 대체 범위는 명시했다. PR #135. |
