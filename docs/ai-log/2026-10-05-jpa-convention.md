# JPA 플러그인을 별도 컨벤션으로 분리하지 않는다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-05, Claude Code 자동 리뷰 |
| 제안 요지 | JPA 플러그인과 allOpen을 별도 컨벤션으로 분리한다. |
| 왜 틀렸나 | 설계 불일치. ADR 0001 결과 절은 두 플러그인과 엔티티 allOpen을 공통 빌드 설정에 두기로 결정했다. 현재 JPA 라이브러리 의존성도 없다. |
| 어떻게 알았나 | [리뷰 1번](https://github.com/moonino/dropgate/pull/37#issuecomment-5994143104)을 docs/adr/0001-kotlin과-spring-boot.md와 대조했다. 현재 구성은 결정과 같다. |
| 대신 한 것 | 공통 설정을 유지한다. 실제 모듈별 분리가 필요해지면 설계 변경부터 검토한다. PR #37 |
