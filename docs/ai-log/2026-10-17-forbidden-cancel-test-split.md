# 남의 주문 취소 테스트를 403 응답과 주문 상태 유지로 나누지 않는다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-17, Claude Code 자동 리뷰 제안 |
| 제안 요지 | OrderCancelTest의 FORBIDDEN 테스트가 403 응답과 주문 상태 유지를 함께 검증하므로 "테스트 하나는 한 가지 개념만 검증한다"에 맞게 두 테스트로 나눈다. |
| 왜 틀렸나 | 과잉. 제안이 코드를 틀리게 만들지는 않지만 규칙이 요구하지 않는 분할이라 필요 없는 변경이다. 제안은 테스트가 규칙을 어긴다고 짚었으나 테스트는 이미 규칙을 지킨다. AGENTS.md는 단언이 여럿이어도 전부 같은 개념이면 된다고 정하고, 남의 주문 취소를 거부한다는 것과 거부에 부작용이 없다는 것은 한 개념의 두 면이다. 테스트 이름 `남의 주문을 취소하면 403 FORBIDDEN을 돌려주고 주문은 그대로 둔다`도 두 검증을 모두 밝힌다. |
| 어떻게 알았나 | 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/83#issuecomment-6230597517) 1번 항목의 "110행 FORBIDDEN 테스트도 403 응답과 주문 상태 유지를 함께 검증하므로 같은 방식으로 나눌 수 있습니다"를 AGENTS.md의 테스트 규칙과 기존 테스트에 대조했다. DropRegistrationTest의 `USER 토큰으로 등록하면 403 FORBIDDEN을 돌려주고 저장하지 않는다`가 거부 응답과 저장 없음을 한 테스트에서 단언하는 같은 형태다. 같은 제안이 [두 번째 리뷰](https://github.com/moonino/dropgate/pull/83#issuecomment-6233138142)와 [세 번째 리뷰](https://github.com/moonino/dropgate/pull/83#issuecomment-6233253519)에도 다시 나왔다. |
| 대신 한 것 | FORBIDDEN 테스트를 403 응답과 주문 상태 CONFIRMED 유지를 함께 단언하는 한 테스트로 유지했다. PR #83 |
