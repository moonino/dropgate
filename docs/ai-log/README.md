# AI 기각 일지

AI(자동 리뷰, 코딩 에이전트)가 준 코드나 지적을 쓰지 않은 사례를 한 건씩 적는다. 파일 이름 YYYY-MM-DD-slug.md. 없는 주는 주간 기록에 0건으로 적는다. 집계는 weekly.md. 모든 열은 그 주에 머지된 PR 기준이다.

양식은 0000-template.md. 다섯 항목을 모두 채운다. "왜 틀렸나"는 아래 원인 중 하나를 앞에 쓴다.

| 원인 | 뜻 |
|---|---|
| 없는 API | 존재하지 않는 메서드, 클래스, 옵션을 썼다 |
| 폐기된 API | 있지만 현재 버전에서 폐기됐거나 동작이 바뀌었다 |
| 설계 불일치 | docs/design/과 다르게 구현했다 |
| 동시성 가정 오류 | 원자성, 순서, 재시도에 대한 가정이 틀렸다 |
| 테스트 불일치 | 테스트가 통과하지 않거나 테스트가 검증을 하지 않는다 |
| 규칙 위반 | CONTRIBUTING.md 규칙(주석, 이름, 300줄)에 어긋난다 |
| 과잉 | 요청 범위를 넘는 변경을 넣었다 |
