행은 `docs/ai-log/weekly.sh w1 2026-10-06 2026-10-12`의 출력을 그대로 붙인다. 세는 방법은 스크립트가 정본이고, 열의 뜻은 다음과 같다.

- 머지 PR: 기간 안에 main에 머지된 PR 번호
- 자동 리뷰 지적: 작성자가 반영 또는 기각으로 시작하는 답글을 단 지적 수. 답글 규칙은 CONTRIBUTING 4절. push 뒤 다시 달린 같은 지적은 답글이 없으므로 세지 않는다
- 기각, 반영: 답글 첫 두 글자로 가른다. 지적 = 기각 + 반영
- 기각 일지 전체: "대신 한 것"에 그 주 PR 번호를 적은 이 폴더의 파일 수. 자동 리뷰 지적 기각, 자동 리뷰 제안 기각, 코딩 에이전트 제안 기각을 모두 더한 것이다. 기각 답글마다 일지가 있어야 하므로, "날짜, 도구"가 자동 리뷰 지적인 파일 수가 기각 열보다 적으면 스크립트가 경고한다. 제안 기각은 답글이 없고, 반영으로 답했지만 지적의 일부를 쓰지 않은 사례도 일지를 남기므로 지적 일지가 기각 열보다 많은 것은 경고하지 않는다
- 기각 원인 1위: 위 파일들의 "왜 틀렸나"에서 마침표 앞 원인 이름 중 최다. 파일이 없으면 없음
- AI 초안 테스트 PR / 테스트 PR: 분모는 src/test/ 아래 파일을 바꾼 PR 수, 분자는 그중 본문 AI 칸에 테스트 초안이라고 적은 PR 수. 템플릿 주석 안의 같은 문구는 거른다
- 시간 절감은 비교군이 없으므로 적지 않는다
