# 기존 모의 사용자 키를 역할로 추가 변경하지 않는다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | MOCK_USERS를 Record<Role, User>로 바꾸고 mock 접두사를 붙이는 사용자 키 구성을 없앤다. |
| 왜 틀렸나 | 과잉. 사용자 키가 발급 토큰처럼 보이는 부분은 userKey 이름으로 이미 분리했다. 실제 인증은 공유 세션 저장소가 발급한 토큰만 사용한다. 기존 픽스처와 테스트의 키를 함께 바꾸는 추가 정리는 이번 세션 회전 기능에 필수가 아니다. |
| 어떻게 알았나 | 문서 대조. [후속 리뷰](https://github.com/moonino/dropgate/pull/133#issuecomment-6260825867)를 2c3f5af의 모의 로그인과 MockSessionStore에 대조했다. userKey는 MOCK_USERS 조회에만 쓰고, 인증과 회전 및 무효화는 저장소가 별도로 발급한 액세스와 리프레시 토큰을 사용한다. |
| 대신 한 것 | userKey 이름과 기존 픽스처 키를 유지했다. 모의 사용자 픽스처 구조를 별도로 바꿀 때 검토한다. PR #133. |
