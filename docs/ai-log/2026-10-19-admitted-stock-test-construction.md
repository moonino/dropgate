# 입장 확인 저장소의 테스트별 조립을 유지한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | 입장 확인을 켠 저장소 생성 세 곳을 필드나 도우미로 모은다. |
| 왜 틀렸나 | 과잉. 각 입장 테스트가 명시적으로 설정하는 객체 조립이며 생산 규칙의 중복은 아니다. 공통 주입 저장소의 입장 꺼짐 기본값과 대비해 본문에서 설정을 드러낸다. |
| 어떻게 알았나 | 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/134#issuecomment-6260993516)을 StockReservationTest와 대조했다. 입장 확인을 켠 세 테스트는 각각 입장 키 부재, 성공 시 소비, 소비 뒤 재요청을 검증하며 같은 생성식은 입력 설정만 조립한다. |
| 대신 한 것 | 설정 조립을 각 테스트에 유지한다. PR #134. |
