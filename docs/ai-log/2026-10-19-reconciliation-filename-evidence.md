# 대조 원본 파일명을 실행별로 남긴다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | 대조 파일 10행을 `reconcile-<경로>-<runId>.json`이라는 한 문장으로 줄여 환경 파일명 표기와 맞춘다. |
| 왜 틀렸나 | 과잉. 환경 버전의 공통 파일명 규칙과 실행별 대조 근거의 목록은 역할이 다르다. 원본 프롬프트는 실제 실행 파일명과 대조 결과를 실행마다 남기도록 요구한다. 표는 번호마다 정확한 파일명을 연결하므로 패턴만 쓰는 것보다 보존 결과를 직접 추적하기 쉽다. 이번 기록에서는 실제 10개 목록을 유지한다. |
| 어떻게 알았나 | 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/161#issuecomment-6263656788)을 #116 원본 프롬프트의 파일명 명시 규칙, 측정 문서의 실행 번호 및 실제 완료 기록 10개와 대조했다. 표의 대조 파일명은 해당 완료 기록의 reconciliationFile과 일치한다. 실제 부하는 이미 10회 완료됐으며 이번 명명 판단을 위해 새 부하나 테스트는 실행하지 않았다. |
| 대신 한 것 | 실행별 대조 파일명 표를 유지한다. 같은 리뷰의 README 띄어쓰기는 후속 문서에서 201 p99로 맞춘다. PR #161. |
