# 문장의 대조 대상을 드러내는 링크 이름을 유지한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | 근거의 링크 이름을 모두 리뷰로 통일한다. |
| 왜 틀렸나 | 과잉. 주문 리뷰와 인증 리뷰를 함께 대조하는 문장에서는 다른 출처를 드러내는 이름이 구분에 도움이 된다. 날짜와 도구 칸의 자동 리뷰 표기는 어떤 PR의 어떤 근거인지를 대신하지 않는다. |
| 어떻게 알았나 | 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/138#issuecomment-6261121708)을 같은 전달 정책에 대한 주문 PR123과 인증 PR124의 출처를 비교하는 문장에 대조했다. |
| 대신 한 것 | 링크 이름은 출처 역할을 보존하고 판단 방식은 기존 템플릿 용어로 맞췄다. PR #138. |
