# 짧은 로그아웃 함수의 실패 문구를 유지한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | HTTP 실패와 연결 예외에서 사용하는 로그 문구를 상수로 묶는다. |
| 왜 틀렸나 | 과잉. 상수 추출은 가능한 정리지만 같은 짧은 함수의 두 분기가 현재 동일한 실패 문구와 서로 다른 진단 값을 기록한다. 동작 결함이 없어 로그아웃 중계와 실패 시 쿠키 정리를 연결하는 이번 범위에서 미룬다. |
| 어떻게 알았나 | 문서 대조. [후속 리뷰](https://github.com/moonino/dropgate/pull/152#issuecomment-6261715415)를 ac1c783의 notifyBackendLogout과 비교했다. HTTP 실패는 status, 연결 예외는 error를 같은 문구와 함께 기록하며 두 분기 모두 쿠키 정리와 이동을 계속한다. |
| 대신 한 것 | 검증 범위를 과장한 테스트 이름은 수정하고 검증된 로그아웃 구현을 유지했다. PR #152. |
