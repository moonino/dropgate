# 범위상 보류한 제안도 기존 분류를 사용한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | 타당하지만 범위 때문에 보류한 제안에 별도 원인 분류를 추가한다. |
| 왜 틀렸나 | 과잉. docs/ai-log/README.md는 원인 분류를 정하고 과잉을 요청 범위를 넘는 변경으로 정의한다. 보류도 이 범주에 속하며 각 이유 본문에서 타당성과 현재 범위를 명시해 실제 오류와 구별한다. 새 분류를 추가하면 이번 일지 기록을 넘어 집계 규칙을 바꾼다. |
| 어떻게 알았나 | 기존 README의 원인 표, 0000-template.md와 범위 보류 파일의 타당성 설명을 대조했다. . [리뷰](https://github.com/moonino/dropgate/pull/138). |
| 대신 한 것 | 기존 분류를 유지하고 타당하지만 채택하지 않은 이유를 각 행에 직접 적는다. PR #138. |
