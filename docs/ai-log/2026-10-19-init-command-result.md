# 초기화 명령에 사용하지 않는 Boolean 반환을 추가하지 않는다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | initialize가 Lua의 1과 0을 Boolean으로 변환해 반환하면 후속 스케줄러가 새 초기화 여부를 알 수 있다. [리뷰](https://github.com/moonino/dropgate/pull/127#issuecomment-6260393720) |
| 왜 틀렸나 | 과잉. 스케줄러의 호출 권한은 별도 DB 트랜잭션에서 영속화한 1회 claim이 결정한다. Lua의 0과 1은 정상 완료이며 새 초기화 여부를 사용하는 후속 동작이 없다. 값을 바꾸는 명령에 쓰지 않는 조회 결과를 노출할 이유가 없다. |
| 어떻게 알았나 | 설계 문서 대조와 테스트. 02 및 ADR 0006, 0007과 후속 claim 스케줄러는 claim 성공 호출만 한 번 실행하고 최초 실패도 자동 재시도하지 않는다. 실제 Redis의 결과 상태와 만료 시각으로 초기화 계약을 검증했다. |
| 대신 한 것 | initialize는 Unit 명령으로 유지하고 권한은 DB claim에서 판단한다. PR #127 |
