# 품절 뒤 구매 이력에 따른 코드 구분을 함께 검증한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | 품절 뒤 기존 구매자의 ALREADY_PURCHASED와 신규 사용자의 SOLD_OUT을 별도 테스트로 나눈다. |
| 왜 틀렸나 | 과잉. 같은 품절 상태에서 구매 이력에 따라 오류를 구분하는 하나의 판정 계약이다. 두 결과를 함께 확인해야 buyers 검사가 stock 검사보다 앞선다는 의미가 드러난다. |
| 어떻게 알았나 | 설계 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/134#issuecomment-6260888510)을 02 문서와 ADR 0007의 검사 순서에 대조했다. 테스트는 마지막 재고를 산 뒤 그 구매자와 신규 사용자에게 각각 요청하고 두 코드를 비교한다. 실제 Redis 7.4 대상 테스트가 통과했다. |
| 대신 한 것 | 품절 비교 테스트를 유지했다. 서로 다른 개념인 입장 키 소비와 재요청의 검사 순서는 별도로 나눴다. PR #134 |
