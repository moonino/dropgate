# DROP_CLOSED 거부 테스트를 409 응답과 재고 미복원으로 나누지 않는다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-17, Claude Code 자동 리뷰 제안 |
| 제안 요지 | OrderCancelTest의 DROP_CLOSED 테스트가 409 응답과 재고가 되돌아가지 않았다는 것을 함께 검증하므로 "테스트 하나는 한 가지 개념만 검증한다"에 맞게 두 테스트로 나눈다. |
| 왜 틀렸나 | 과잉. AGENTS.md 규칙은 "단언이 여럿이어도 전부 같은 개념이어야 한다"이고, 거부 응답과 거부에 부작용이 없다는 것은 마감 뒤 취소 거부라는 한 개념의 두 면이다. 제안은 단언 개수를 개념 개수로 읽어 규칙이 요구하지 않는 분리를 요구했다. README 원인 중 정확히 맞는 것은 없고, 필요 없는 변경을 넣자는 제안이라 과잉에 가장 가깝다. 테스트 이름 `마감 시각이 지난 드롭의 주문을 취소하면 409 DROP_CLOSED를 돌려주고 재고를 되돌리지 않는다`가 두 검증을 모두 밝힌다. |
| 어떻게 알았나 | 문서 대조. [리뷰 제안](https://github.com/moonino/dropgate/pull/83#issuecomment-6230597517) 1번을 AGENTS.md의 테스트 규칙 문장과 대조했고, 기존 DropRegistrationTest의 `USER 토큰으로 등록하면 403 FORBIDDEN을 돌려주고 저장하지 않는다`가 거부 응답과 저장 없음을 한 테스트에서 단언하는 같은 형태임을 확인했다. 같은 날 뒤 차례 리뷰([리뷰 제안](https://github.com/moonino/dropgate/pull/83#issuecomment-6233138142), [리뷰 제안](https://github.com/moonino/dropgate/pull/83#issuecomment-6233253519))에서도 같은 분리가 다시 제안됐다. 이 차례들에 대한 별도 기각 기록은 없고, 브랜치의 테스트는 하나로 남아 있다. |
| 대신 한 것 | 409 DROP_CLOSED 응답과 남은 재고 9 유지를 한 테스트에 그대로 둔다. PR #83 |
