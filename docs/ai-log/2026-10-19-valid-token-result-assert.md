# 정상 토큰의 조회와 통과 결과를 함께 확인한다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | 무효화되지 않은 토큰 테스트의 role 단언을 제거하고 lookupCount 단언만 남긴다. |
| 왜 틀렸나 | 과잉. 이 테스트는 무효화되지 않은 USER 토큰이 한 번의 확인 뒤 정상 사용자로 통과하는 한 계약을 검증한다. 역할 값과 조회 횟수는 그 정상 경로의 결과와 외부 확인이며 별도 개념이 아니다. 기존 다른 테스트는 ADMIN 사용자 식별자와 역할을 읽는 입력을 확인한다. AGENTS.md는 같은 개념의 여러 단언을 허용한다. |
| 어떻게 알았나 | 문서 대조. [후속 리뷰 제안](https://github.com/moonino/dropgate/pull/132#issuecomment-6260786855)을 테스트 이름과 입력, AGENTS.md의 같은 개념 단언 규칙에 비교했다. 최소 스텁 Red에서는 조회 횟수 단언이 실패했고 실제 조회 뒤에는 정상 결과와 조회 1회가 함께 통과했다. |
| 대신 한 것 | 정상 USER 결과와 조회 1회 단언을 같은 테스트에 유지한다. PR #132. |
