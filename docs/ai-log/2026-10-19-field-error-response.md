# 모의 필드 오류 응답을 추가로 통합하지 않는다

| 항목 | 내용 |
|---|---|
| 날짜, 도구 | 2026-10-19, Claude Code 자동 리뷰 제안(요약 댓글의 제안) |
| 제안 요지 | 재발급과 드롭 등록의 400 본문을 respondWithFieldErrors로 합쳐 메시지와 형식을 통일한다. |
| 왜 틀렸나 | 과잉. 두 응답은 API별 메시지가 다른 유효한 필드 오류이며 공통 형식은 이미 같다. 응답 생성 함수를 합치는 정리는 가능하지만 모의 세션 회전과 무효화 기능에 필요한 오류 수정은 아니다. |
| 어떻게 알았나 | 문서 대조. [후속 리뷰](https://github.com/moonino/dropgate/pull/133#issuecomment-6260825867)를 2c3f5af의 mock-handlers.ts와 대조했다. 재발급과 드롭 생성의 400 응답은 모두 VALIDATION_FAILED와 message, errors를 사용하고 필드와 안내 문구만 입력에 맞게 다르다. |
| 대신 한 것 | 필드 추출과 인증 공유가 완료된 핸들러를 유지했다. 공통 응답이 더 늘어날 때 다시 판단한다. PR #133. |
