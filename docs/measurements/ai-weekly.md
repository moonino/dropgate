# AI 활용 주간 기록

주마다 한 행. 세는 법은 각 열 아래. 기각 사례 본문은 docs/ai-log/.

| 주 | 자동 리뷰 지적 | 반영 | 기각 | AI 초안 테스트 / 전체 테스트 PR | 기각 일지 건수 | 기각 원인 1위 |
|---|---|---|---|---|---|---|
| w1 | | | | | | |

- 자동 리뷰 지적: 그 주 머지된 PR의 Claude 리뷰 댓글 수. 반영과 기각은 답글로 센다. 반영 + 기각 = 지적.
- AI 초안 테스트: PR 본문 AI 칸에 "테스트 초안"이 있는 PR 수 / 테스트가 든 PR 수.
- 기각 일지 건수와 원인 1위: docs/ai-log/ 그 주 파일 수와 "왜 틀렸나" 원인 집계.
- 시간 절감은 비교군이 없으므로 적지 않는다.
